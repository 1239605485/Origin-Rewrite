# OriginRewrite｜起源重构 v1.0 正式版

> Android ARM64 · Terraria 手机版 1.4.x · TEFKernel / KernelLoader · 单机

## 模组总览

**起源重构**是一套以“世界逐步失衡”为主题的怪物强化系统。它不替换原版的怪物生态，
而是在怪物完成原版生成后，按世界进度、难度、当前世界规则、玩家所在环境与天气，为其中一部分怪物赋予重构身份。

重构后的怪物会拥有更高的属性、不同的战斗节奏、阶段性奖励和独立播报。整个系统由五层共同决定：

1. **世界进度**决定可出现的层级与基础强度；
2. **世界规则**决定本次世界会话的整体倾向；
3. **环境规则**由深度、生态、天气和昼夜决定；
4. **重构体层级**决定属性、奖励和 AI 能力预算；
5. **怪物原生类型**决定使用冲锋、远射、俯冲、相位等哪类兼容动作。

模组保留原版掉落和原版金币流程，不使用 BNM，也不在客户端单独抽取或结算。当前版本仅面向 Android ARM64 单机环境。

## 重构体生成与层级

### 总体生成概率

每只符合资格的原版敌怪在完成生成提交时只抽取一次；不会在每一帧重复抽取，也不会因为怪物槽位复用而继承旧状态。

| 游戏模式 | 重构体总体概率 | 属性模式倍率 |
|---|---:|---|
| 普通 | 20% | 生命 ×1.00、伤害 ×1.00、防御 ×1.00 |
| 专家 | 30% | 生命 ×1.15、伤害 ×1.10、防御 ×1.05 |
| 大师 | 40% | 生命 ×1.35、伤害 ×1.25、防御 ×1.10 |
| 天顶 / 传奇 | 50% | 生命 ×1.60、伤害 ×1.45、防御 ×1.15 |
| 旅行 | 20% | 沿用普通模式属性；可由独立倍率配置调整 |

默认同屏最多存在 **8 只重构体**。Boss、城镇 NPC、友好单位、雕像生成物、召唤物、分裂物与多节虫等高风险来源默认不参与普通重构抽取。

### 三档重构体

| 层级 | 显示前缀 | 设计定位 | 基础特征 |
|---|---|---|---|
| 异化体 | `异化体·` | 轻量强化、频率最高 | 1 个轻量行为变化；更适合作为前期常见压力。 |
| 灾变体 | `灾变体·` | 主动威胁、战斗转折 | 1 个主要主动行为；会使用冲锋、护盾、远射或相位类动作。 |
| 终焉体 | `终焉体·` | 高风险稀有敌人 | 1 个互斥标志能力：相位、狂怒或召唤；拥有最高属性与奖励档。 |

重构体的名称会保留原怪物名并加上层级前缀。灾变体、终焉体、世界规则、地形和天气均使用独立的显眼淡色中文播报，便于玩家在战斗中区分来源。

## 世界规则

进入世界后，系统会从规则池中随机抽取 **2–4 条不重复规则**；规则按互斥关系过滤，避免出现互相抵消或叠加过强的组合。每经过 **3 个游戏日**，世界规则会重新抽取一次，并保留本次世界会话的规则历史。

规则不是每帧叠加：它会在后续怪物生成时写入快照。规则更替后，已经在场的重构体不会被重新计算，因此一只怪物从生成到死亡都保持同一套属性与行为依据。

| 世界规则 | 生效效果 | 条件 / 互斥 |
|---|---|---|
| **重构潮汐** | 重构体总体概率 ×1.25；异化体额外奖励触发率 +10 个百分点。 | 与“暴风边境”互斥。 |
| **强敌世界** | 重构体生命 ×1.15、接触伤害 ×1.15。 | 与“玻璃炮”互斥。 |
| **丰收契约** | 异化体额外奖励触发率 +15 个百分点；高阶奖励质量权重 ×1.10。 | 不会产生第二个额外奖励槽。 |
| **暴风边境** | 当前存在天气时，重构体总体概率 ×1.15。 | 无天气时不激活；与“重构潮汐”互斥。 |
| **夜行法则** | 夜间生成的重构体移动节奏 ×1.10。 | 仅在夜间快照中激活。 |
| **深渊回响** | 地下或洞穴区域中，灾变体候选权重 ×1.15。 | 仅在地下 / 洞穴快照中激活。 |
| **邪恶侵染** | 腐化与猩红环境优先匹配对应元素和兼容攻击效果。 | 仅在腐化 / 猩红快照中激活。 |
| **玻璃炮** | 重构体生命 ×0.85、接触伤害 ×1.15。 | 与“强敌世界”互斥。 |

为防止极端叠加，规则的生命、伤害、防御合计倍率会受到上限约束；概率、奖励与额外属性同样设有独立封顶。规则只影响可兼容的能力池，不会让一只怪物同时获得多个超出层级预算的主动技能。

## 环境规则

环境规则以**玩家当前所在地**为基准：当玩家进入新地形时，会收到一次地形规则播报；之后生成的重构体会采样该位置的深度、生态、特殊地点、天气与昼夜。环境变化只影响后续生成，不会倒灌修改场上怪物。

### 深度

| 环境 | 对后续重构体的影响 |
|---|---|
| 地表 | 森林环境会使异化体候选权重 ×1.10。 |
| 地下 / 洞穴 | 生命 ×1.05、防御 ×1.05，灾变体候选权重 ×1.15。 |
| 地狱 | 困难模式后，终焉体候选权重 ×1.15；优先匹配火焰类环境元素。 |

### 生态

| 生态 | 对后续重构体的影响 |
|---|---|
| 沙漠 | 伤害 ×1.08；灾变体候选权重 ×1.05。 |
| 雪原 | 防御 ×1.08、伤害 ×0.96；优先匹配冰霜元素。 |
| 丛林 | 生命 ×1.06、伤害 ×1.06；灾变体候选权重 ×1.08；优先匹配毒性元素。 |
| 神圣 | 生命 ×1.06、防御 ×1.05；灾变体候选权重 ×1.10。 |
| 腐化 | 生命 ×1.08、伤害 ×1.08；灾变体候选权重 ×1.10；优先匹配腐化元素。 |
| 猩红 | 生命 ×1.08、伤害 ×1.10、防御 ×1.04；灾变体候选权重 ×1.10；优先匹配猩红元素。 |
| 海洋、地牢、发光蘑菇洞、天空 | 作为特殊地点标签参与环境宝匣与能力兼容性选择；特殊地点优先级高于普通生态。 |

### 天气与时间

| 天气 / 时间 | 对后续重构体的影响 |
|---|---|
| 血月 | 总体重构概率 ×1.15；奖励质量 ×1.10。 |
| 日食 | 灾变体、终焉体候选权重各 ×1.10；奖励质量 ×1.10。 |
| 降雨 | AI 强度 ×1.05，偏向水 / 雷系兼容攻击。 |
| 沙尘暴 | 移动节奏 ×1.10、AI 强度 ×1.05；沙漠单位优先强化移动或远射中的一项。 |
| 暴雪 / 霜月 | AI 强度 ×1.05；雪原攻击优先匹配冰霜效果。 |
| 南瓜月 / 史莱姆雨 | AI 强度 ×1.08；地狱或南瓜月优先匹配火焰元素。 |
| 大风天 | 移动节奏 ×1.08、AI 强度 ×1.03；飞行单位更容易获得短暂加速。 |
| 夜间 | 若“夜行法则”处于激活状态，移动节奏额外 ×1.10。 |

## 世界阶段与属性

世界永久阶段由困难模式与 Boss 进度决定，优先级为：终局 > 世纪之花后 > 世纪之花前 > 困难模式前期 > 前期。血月、日食等事件只属于环境快照，不会改变世界永久阶段。

| 世界阶段 | 进入条件 | 异化体：生命 / 伤害 / 额外防御 | 灾变体：生命 / 伤害 / 额外防御 | 终焉体：生命 / 伤害 / 额外防御 |
|---|---|---|---|---|
| 起源稳定期（前期） | 尚未进入困难模式 | ×1.25 / ×1.10 / +2 | ×1.65 / ×1.30 / +4 | 不出现 |
| 深层扰动期（困难模式前期） | 已进困难模式，三个机械 Boss 未全部击败 | ×1.45 / ×1.25 / +4 | ×2.10 / ×1.60 / +7 | ×3.20 / ×2.00 / +12 |
| 生命重构期（世纪之花前） | 三个机械 Boss 均已击败，世纪之花未击败 | ×1.70 / ×1.45 / +6 | ×2.70 / ×2.00 / +10 | ×4.20 / ×2.50 / +16 |
| 起源崩解期（世纪之花后） | 世纪之花已击败，月亮领主未击败 | ×2.00 / ×1.70 / +8 | ×3.40 / ×2.50 / +14 | ×5.50 / ×3.10 / +22 |
| 终局重构期 | 月亮领主已击败 | ×2.40 / ×2.00 / +10 | ×4.40 / ×3.10 / +18 | ×7.00 / ×3.80 / +30 |

上表的阶段倍率建立在原版最终基础属性上，再叠加当前难度、世界规则、环境快照和词缀的合法修正。怪物如果已经受伤才完成提交，生命会按原生命比例换算，不会无条件回满。

除阶段属性外，各层级还拥有下列固定特性：

| 层级 | 防御倍率 | 击退减免 | 体型倍率 | 金币价值倍率 | 重构体名额占用 | AI 强度 |
|---|---:|---:|---:|---:|---:|---:|
| 异化体 | ×1.10 | 20% | ×1.05 | ×1.50 | ×1.15 | ×1.00 |
| 灾变体 | ×1.20 | 40% | ×1.10 | ×3.00 | ×1.35 | ×1.15 |
| 终焉体 | ×1.30 | 60% | ×1.15 | ×6.00 | ×1.75 | ×1.30 |

## 怪物 AI

所有附加 AI 都遵循“**原版 AI 先执行，重构动作后叠加**”的原则。每次动作使用统一五阶段流程：

`准备 Ready → 预警 Telegraph → 生效 Active → 恢复 Recovery → 冷却 Cooldown`

这让玩家能先看到动作预警，再应对爆发；AI 不会跳过原版逻辑，也不会无限连发。

### 怪物类型与主动作

| 怪物类型 | 主动作 | 行为说明 |
|---|---|---|
| 近战 | 冲刺 / 突进 | 在预警后短距离冲向目标，改变接近节奏。 |
| 远程 | 投射物爆发 | 在可用的原生投射物接口下，进行受数量限制的远射。 |
| 飞行 | 空中巡航 → 锁定俯冲 | 先在空中随机巡航，再锁定玩家当时站立的位置，以固定目标向量俯冲；不会持续追踪玩家的新位置。 |
| 蠕虫 | 掘进 / 节奏变化 | 保持原版多节结构，不传送、不改变节数。 |
| 群体 | 短促冲刺 | 提升集群的切入节奏，不叠加第二套独立攻击。 |
| 特殊 / 施法 | 相位或受限远射 | 保留原生施法逻辑，再叠加受限的相位、远射或狂暴。 |

### 各层级 AI 预算

| 层级 | AI 预算与阶段限制 |
|---|---|
| 异化体 | 仅 1 个轻量变化：迅捷、坚韧、狂暴或吸血中的兼容效果。前期即可出现，不追加大范围独立弹幕。 |
| 灾变体 | 1 个主要主动动作，外加至多 1 个弱被动。前期仅使用可读性较强的冲锋或低强度护盾；困难模式后远程怪可使用 3 发窄扇形远射，其他类型在冲锋与相位中选择其一。 |
| 终焉体 | 1 个互斥标志能力。困难模式前期只开放相位或狂怒；世纪之花前后开始可在相位、狂怒、召唤中选择。召唤最多 2 只同类小怪；相位可带最多 5 发窄扇形远射；狂怒只在生命首次跨过 25% 时触发一次。 |

投射物、召唤和相位免伤均设有独立数量与频率上限。若目标游戏版本缺少某个精确原生接口，只有该项附加动作关闭，怪物会继续使用原版 AI，不影响属性、规则和其他已验证能力。

## 掉落与结算

原版掉落和金币流程始终优先保留。重构体最多生成 **1 个额外奖励槽**，且每只怪只允许结算一次：

| 层级 | 额外奖励规则 |
|---|---|
| 异化体 | 默认 20% 概率触发；奖励为当前阶段的材料、药水或弹药。 |
| 灾变体 | 必定尝试 1 个奖励槽：70% 材料 / 矿物、20% 药水 / 弹药、10% 合法装备 / 饰品。 |
| 终焉体 | 必定尝试 1 个奖励槽：环境宝匣、合法装备 / 饰品或大份阶段材料三选一。 |

奖励只从原版已启用、符合当前进度且不属于 Boss 袋、Boss 召唤物、专属 Boss 掉落或关键进度物品的白名单中选择。物品生成后还会校验返回槽位；无法确认成功时，不会把空槽当作已发放奖励。

## 兼容性与运行原则

- 仅支持 **Android ARM64**，目标游戏版本为 `1.4.5.8.5`，兼容范围 `1.4.4.0–1.4.5.8.5`。
- 模组以 `SetDefaults` 记录原版基准，并以首次确认 `active=true` 的 `NPC.AI()` 回调作为唯一生成提交点。
- 每只重构体使用 `worldSessionId + npcSlot + generationId` 识别，防止怪物槽位复用污染状态。
- 世界、环境、天气和进度都在生成时冻结为快照；规则切换不会重新强化场上怪物。
- 所有播报提供中文文本与分通道颜色；重复事件会被消息 ID、版本号与冷却共同去重。
